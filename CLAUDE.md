# Project: exodigo
Take-home preparation for the Exodigo Computer Vision interview. The task
(`Interview_Preparation.pdf`, sample panoramas in `images/`) is a system design question:
detect manholes in Google Street View panoramas, classify them by cover type, and output
geospatial detections. No code is required; "done" is a clear, defensible design and
presentation material for a ~1 hour technical discussion.

## Deviations from my global conventions
- Mostly a non-code project. The Python and TDD rules apply only to code that exists
  (today: `scripts/session_to_md.py` and its test, plus any analysis scripts we add).
- Writing conventions for design docs and slides: plain English, no dashes (hyphen only),
  state every assumption explicitly and give the reason for each decision.
- Every session is logged under `ai-chats/` (see `ai-chats/README.md`). Keep the curated
  `NN-slug.md` file current each turn; `/save-chat` refreshes it on demand.

## Local state / do-not-touch
- `ai-chats/_auto/`: machine-generated by hooks, gitignored, never hand-edit.
- `local/`: gitignored working inputs (readable). `.secrets/`: denied.

## Running
- Setup: `python3 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt`
- Tests: `.venv/bin/python -m pytest`
